# My First HTML Project

My very first website, built with plain HTML and CSS in Visual Studio Code and pushed to GitHub.

## About

This project is a simple one-page site that marks my first step into web development — writing basic HTML structure, styling it with CSS, and learning the Git/GitHub workflow (add, commit, push).

## What's inside

- `index.html` — the full website (structure + inline styling)

## What I learned

- Setting up a project folder and opening it in VS Code
- Writing basic HTML: `head`, `body`, headings, paragraphs, lists
- Styling a page with CSS
- Using Git to track and commit changes
- Pushing a local repository to GitHub
