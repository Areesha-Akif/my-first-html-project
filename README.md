# My First HTML Project

My very first website, built with plain HTML and CSS in Visual Studio Code and pushed to GitHub.

## About

This project is a simple one-page site that marks my first step into web development — writing basic HTML structure, styling it with CSS, and learning the Git/GitHub workflow (add, commit, push).

## Features

- Clean, single-page layout with header, main content, and footer
- Custom CSS styling (colors, typography, spacing) — no external frameworks
- Fully responsive text and layout that works on both desktop and mobile
- Sections for About, What I Learned, and What's Next
- Simple, readable code — great for beginners to study or build on

## Project Structure

```
my-first-html-project/
│
├── index.html      # Main HTML file (structure + CSS styling)
└── README.md       # Project documentation (this file)
```

## How to Use

1. Clone or download this repository:
   ```
   git clone https://github.com/YOUR-USERNAME/my-first-html-project.git
   ```
2. Open the project folder.
3. Double-click `index.html`, or open it in any web browser — no installation or build steps needed.
4. To edit the page, open `index.html` in a code editor like VS Code and make your changes.

## What I Learned

- Setting up a project folder and opening it in VS Code
- Writing basic HTML: `head`, `body`, headings, paragraphs, lists
- Styling a page with CSS
- Using Git to track and commit changes
- Pushing a local repository to GitHub
